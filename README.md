# LawMadeSimple

**KnowYourRight | Understand the Law**

LawMadeSimple is a legal information website that explains Nigerian laws and legal rights in plain, easy-to-understand English. No legal jargon, just the facts people need to know.

## Overview

Many people do not know their legal rights because the law is often written in complex language. This project is the front end of a website that makes legal information accessible to everyone, starting with a homepage that introduces the site and lists the key legal topics it covers.

## Features

- Responsive-ready navigation bar with links to Home, Topics, About and Contact
- "Ask a question" call-to-action button
- Hero section introducing the purpose of the site
- Topic cards for quick browsing

## Topics Covered

| Topic | Description |
|---|---|
| Family Law | Marriage, divorce, child custody and inheritance |
| Tenancy Law | Rent, notice, eviction rules and tenant obligations |
| Employment Rights | Contracts, wages, leave, termination and workplace protection |
| Constitutional Law | Coming soon |
| Criminal Law | Coming soon |
| Latin Maxims | Latin maxims explained clearly |

## Getting Started

1. Download or clone this repository:
   ```bash
   git clone <your-repository-url>
   ```
2. Open the project folder.
3. Make sure `index.html` and `project.css` are in the same folder.
4. Open `index.html` in any web browser.

No installation or build step is required.
